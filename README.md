# Cyber Awareness Starter Kit
A beginner-friendly cyber awareness project for a fictional workplace.
# Purpose
This project provides simple cybersecurity in a fictional warehouse or retail workplace.

# Scenario
An employee receives a test message asking them to scan a QR code and confirm payroll information. The message creates urgency and may be an attempt to steal login or personal information.
# Questions to ask
    Was the message expected?
    Does the sender's information look familiar?
    Is the message creating fear or urgency?
    Is it asking for a password or personal information?
    How can the request be verified using a trusted contact method/
# First Reccommendation
Do not scan the QR code or reply to the message. Report it to a supervisor or the organization's designated security contact.
